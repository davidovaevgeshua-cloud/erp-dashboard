# ERP и P/E индекса Мосбиржи

Дашборд форвардной премии за риск (ERP) и мультипликатора P/E индекса Мосбиржи
с автоматическим обновлением данных через MOEX ISS API.

**Онлайн-версия:** https://davidovaevgeshua-cloud.github.io/erp-dashboard/

## Что внутри

| Раздел | Содержание |
|---|---|
| 1. Форвардный ERP | дневной ряд с сужением таймфрейма + столбцы по годам 2014–2025, кварталам 2026 и текущему значению |
| 2. P/E индекса | те же два формата, бенчмарк — средний P/E 2016–2018 (6.2) |
| 3. Совмещённая динамика | три синхронизированные панели IMOEX / ОФЗ 5Y / ERP с 2025 года |

## Методика

- `COE = EPS_fwd / IMOEX`, `ERP = COE − OFZ_5Y`, `P/E = IMOEX / EPS_fwd`
- Форвардный EPS задан в `core.py`: `EPS_FORWARD = {2025: 760, 2026: 590}`
- Доходность ОФЗ 5Y считается из параметров кривой бескупонной доходности Мосбиржи
  по формуле Нельсона–Сигеля с девятью гауссовыми поправками
- Среднее и медиана на столбчатых графиках считаются только по завершённым годам;
  кварталы текущего года и «Сейчас» в базу расчёта не входят
- Кварталы 2026 года — среднее дневных значений внутри квартала

## Файлы

| Файл | Назначение |
|---|---|
| `docs/index.html` | статичный дашборд для GitHub Pages |
| `core.py` | загрузка данных с MOEX ISS и построение графиков |
| `build_static.py` | пересобирает `docs/index.html` со свежими данными |
| `app.py` | интерактивная Dash-версия с кнопкой обновления |
| `erp_daily.csv` | дневной ряд: IMOEX, ОФЗ 5Y, EPS, COE, ERP, P/E |
| `erp_quarterly.csv`, `pe_quarterly.csv` | агрегаты для столбчатых графиков |

## Запуск локально

```bash
pip install -r requirements.txt
python build_static.py      # пересобрать статичный HTML со свежими данными
python app.py               # Dash-версия на http://127.0.0.1:8050
```

## Автообновление

Workflow `.github/workflows/update.yml` запускается шесть раз в торговый день:
**9:50, 11:50, 13:50, 15:50, 17:50 и 19:30 МСК**, только по будням.

- Внутри сессии текущий день перезаписывается (upsert по дате), а не дублируется:
  берётся текущая свеча IMOEX и живая кривая КБД (`/iss/engines/stock/zcyc.json`).
- Закрытые дни берутся из исторического эндпоинта и больше не пересчитываются.
- Если данные не изменились (праздник, пауза в торгах), HTML не пересобирается
  и коммит не создаётся.
- Если ISS недоступен с раннера GitHub (он находится за пределами РФ), сборка не падает —
  используются сохранённые CSV, а причина выводится в шапке страницы.

Расписание GitHub Actions не гарантирует точность до минуты: при нагрузке платформы
запуск может сдвинуться на 5–20 минут.

## Деплой интерактивной версии

Для живой кнопки обновления нужен хостинг с Python. На Render:
build command `pip install -r requirements.txt`, start command `gunicorn app:server`.

Источник данных: [MOEX ISS API](https://iss.moex.com/iss/reference/).
